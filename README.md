# Sistema de Log de Produtos - TP1 Engenharia de Software

## 👥 Equipe e Papéis
* **Jonathan Barbosa do Carmo Machado**: Desenvolvedor Full-stack.


## 🎯 Objetivo do Sistema
O sistema consiste em uma aplicação web para o gerenciamento de inventário, permitindo o registro e controle de produtos com informações de preço, descrição e estoque. A ferramenta busca oferecer uma solução simples e útil para o monitoramento de mercadorias, integrando um sistema de autenticação para garantir que apenas usuários autorizados gerenciem os dados.

## 🛠 Tecnologias Utilizadas
* **Framework**: TanStack Start (React).
* **Estilização**: Tailwind CSS.
* **Linguagem**: TypeScript/JavaScript.
* **Banco de Dados**: SQLite.
* **Agentes de IA**: Gemini e Claude Code (Obrigatórios conforme diretrizes do TP1).
* **Controle de Versão**: GitHub.

## 📝 Histórias de Usuário
Conforme os requisitos de ~2 histórias por membro do time:

1. **Acesso ao Sistema**: Como administrador, quero realizar login para acessar as funcionalidades de gestão de estoque com segurança.
2. **Cadastro de Itens**: Como usuário, quero cadastrar novos produtos (nome, descrição, preço, estoque) para manter o catálogo atualizado.
3. **Consulta de Inventário**: Como usuário, quero visualizar uma lista de todos os produtos para conferir o status geral do estoque.
4. **Edição de Preços**: Como gestor, quero alterar o preço de um produto para refletir mudanças no mercado.
5. **Ajuste de Quantidade**: Como estoquista, quero atualizar o nível de estoque para registrar entradas e saídas de mercadorias.
6. **Remoção de Produtos**: Como administrador, quero excluir itens obsoletos para manter a base de dados organizada.
7. **Busca por Nome**: Como usuário, quero filtrar produtos por nome para localizar itens específicos rapidamente.
8. **Detalhes do Produto**: Como usuário, quero visualizar a descrição completa de um item para entender suas especificações.
